Flare the Peace Away

Building this game was a deep dive into the "behind-the-scenes" of computing. 
Unlike modern languages, every bubble movement and keystroke required direct manipulation of registers and memory addresses. 
It was a challenging yet rewarding way to understand how software talks to hardware.

Since the game runs on some pretty specific hardware interrupts and old-school VGA modes, a video just wouldn't do it justice. 
Instead, I’ve put together the SKY-FLARE GALLERY so you can actually savor every second of the vibe and all the effort that 
went into this Assembly grind
